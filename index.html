Entri Data

Sambungkan dulu ke Google Spreadsheet.

Spreadsheet utama juga menyimpan akun pengguna dan pengaturan (di tab tersembunyi “_pengaturan”). Admin bisa mengarahkan data ke spreadsheet lain nanti.

Cara mendapatkan Client ID (sekali saja, gratis)
  1. Buka console.cloud.google.com, masuk dengan akun Google, lalu buat Project baru.
  2. Menu APIs & Services → Library, cari Google Sheets API, klik Enable.
  3. Menu OAuth consent screen (atau Google Auth Platform): pilih External, isi nama aplikasi dan email. Di bagian Test users, tambahkan email Google semua orang yang akan memakai aplikasi ini.
  4. Menu Credentials → Create credentials → OAuth client ID, jenis Web application. Di Authorized JavaScript origins isi alamat situs ini:
  5. Salin Client ID yang muncul dan tempel di kolom di atas.
  6. Buka spreadsheet-nya, klik Bagikan, dan beri akses Editor ke email Google yang akan dipakai.

Saat Google menampilkan “Google hasn’t verified this app”, pilih Lanjutkan. Itu normal untuk aplikasi pribadi.

Entri Data

Spreadsheet tujuan data

Baris 1 sheet dipakai sebagai judul kolom. Kalau nama sheet belum ada, sheet dibuat otomatis. Perubahan berlaku untuk semua pengguna setelah disimpan.

Perangkat lain

Agar HP atau laptop lain tidak perlu mengetik Client ID dan link, bagikan tautan setup ini.

Kolom isian

Tiap kolom di sini menjadi satu kolom di spreadsheet. Kolom baru otomatis ditambahkan di sebelah kanan, data lama tidak berubah.

Nomor / kode cocok untuk HP, NIK, rekening: angka berapa pun disimpan sebagai teks supaya angka 0 di depan tidak hilang.

Pengguna

Admin bisa mengatur spreadsheet, kolom, dan pengguna. Pengguna biasa hanya bisa mengisi data.
